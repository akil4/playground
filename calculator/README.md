# Simple Web Calculator

**[Live Demo](https://akil4.github.io/calculator/)** | **[Repository](https://github.com/akil4/calculator)**

A basic, interactive web-based calculator built with HTML, CSS, and vanilla JavaScript.

## Features

*   **Basic Arithmetic:** Supports addition (`+`), subtraction (`-`), multiplication (`*`), and division (`/`).
*   **Chained Operations:** Evaluate continuous calculations seamlessly (e.g., `2 + 3 - 4`).
*   **Clear Functionality:** Reset your calculations at any time using the `C` button.
*   **Responsive Design:** Uses CSS Grid and Flexbox for a clean, centered layout.

## Technologies Used

*   **HTML5:** Structure of the calculator.
*   **CSS3:** Styling, grid layout, and aesthetic adjustments.
*   **JavaScript (ES6):** Core logic for operations, event handling, and DOM manipulation.

## Getting Started

To run this project locally, simply clone the repository and open `index.html` in your web browser. No build steps or local servers are required!

```bash
git clone https://github.com/akil4/calculator.git
cd calculator
# Open index.html in your preferred browser
```
